Mansioni e Piano di Lavoro

Attività Generali dell'Azienda

L'azienda svolge una vasta gamma di attività nel settore dell'Information Technology. Durante il mio stage, ho potuto osservare e partecipare a diverse aree operative:

💻 Sviluppo Software

Il team di sviluppo lavora su diversi progetti, dalla creazione di applicazioni web responsive alla realizzazione di software enterprise. Utilizza metodologie agile e segue rigidi processi di quality assurance. Ho partecipato allo sviluppo di moduli PHP e alla creazione di interfacce React.

🔧 Manutenzione Infrastrutture

Il team DevOps e System Administration gestisce i server, il cloud e l'infrastruttura a supporto dei servizi. Ho acquisito conoscenze di configurazione Linux, gestione database PostgreSQL e Docker containerizzazione.

🛡️ Cyber Security

Il reparto security effettua penetration test, auditing e implementa misure di protezione dati. Ho partecipato a sessioni di formazione sulla sicurezza del codice e best practices di password management.

📊 Data & Analytics

Analisi dati e business intelligence per supportare le decisioni aziendali. Ho imparato a utilizzare SQL per estrarre insights da database e a visualizzare dati con Python e Tableau.

📞 Support Tecnico

Un team fornisce supporto ai clienti per problematiche tecniche e richieste di aiuto. Ho assistito nei ticket di supporto e imparato a gestire escalation dei problemi.

⚙️ Consulenza IT

I consulenti aiutano i clienti a identificare soluzioni IT appropriate. Ho partecipato a riunioni con clienti per comprendre i loro fabbisogni e proporre implementazioni.

Piano di Lavoro Settimanale

Di seguito è riportato un esempio del piano di lavoro settimanale durante il mio stage. Le attività sono state distribuite per sviluppare competenze diverse:

Giorno Orario Attività Principale Competenze Sviluppate Outcome/Deliverables
Lunedì 8:30-16:30 Riunione Team + Sviluppo Frontend React, JavaScript ES6, HTML/CSS Componenti UI realizzate e testate
Martedì 8:30-16:30 Backend Development PHP, API REST, Database Design Endpoints API implementati
Mercoledì 8:30-16:30 DevOps & Infrastructure Linux, Docker, CI/CD Pipelines Environment configurato e deployment automatizzato
Giovedì 8:30-16:30 Testing & Quality Assurance Unit Testing, Integration Testing, Bug Fixing Test suite creata e bug risolti
Venerdì 8:30-13:00 Code Review + Formazione Best Practices, Security, Performance Feedback su codice e miglioramenti implementati

Nota: Il piano settimanale è stato costruito per fornire un'esperienza trasversale nell'intero stack di sviluppo software, dalla progettazione al deployment in produzione.
