Tag HTML e CSS degli esercizi precedenti

1. Struttura base di una pagina HTML

Le pagine web sono costruite con tag HTML, cioè elementi che danno una struttura logica al contenuto.

  • <!DOCTYPE html>: indica che il documento è in HTML5.
  • <html lang="it">: contiene tutta la pagina e indica la lingua.
  • <head>: contiene informazioni non visibili, come charset, viewport e collegamenti CSS.
  • <meta charset="UTF-8">: permette di usare caratteri speciali come le lettere accentate.
  • <meta name="viewport" ... >: rende la pagina adattabile ai dispositivi mobili.
  • <title>: imposta il titolo della scheda del browser.
  • <link rel="stylesheet" href="style.css">: collega il file CSS esterno.
  • <body>: contiene tutto ciò che l'utente vede.

2. Tag usati per creare la pagina

  • <header>: parte iniziale della pagina, con titolo o introduzione.
  • <nav>: contiene il menu di navigazione.
  • <ul> e <li>: creano liste puntate.
  • <a href="...">: crea un link ad altre pagine o siti.
  • <main>: contiene il contenuto principale della pagina.
  • <section>: separa blocchi di contenuto.
  • <h1> - <h6>: titoli e sottotitoli in ordine di importanza.
  • <p>: paragrafo di testo.
  • <strong>: testo in grassetto.
  • <img>: inserisce un'immagine con attributi come src e alt.
  • <div>: contenitore generico usato per creare layout.
  • <footer>: parte finale con contatti, crediti o link utili.

3. Tag dei moduli e dei form

Nei vari esercizi sono stati usati anche i form per raccogliere dati dell'utente.

  • <form>: contiene i campi del modulo.
  • <label>: descrive il campo del modulo.
  • <input>: campo di inserimento; può essere text, email, password, date, number, color, radio, checkbox, file.
  • <select> e <option>: menu a tendina.
  • <textarea>: area per scrivere testi lunghi.
  • <fieldset>: raggruppa più campi correlati.
  • <legend>: titolo del gruppo di campi.
  • <button>: bottone con azioni come invio o reset.

4. Cos'è il CSS

Il CSS (Cascading Style Sheets) serve a dare stile alla pagina: colori, spazi, margini, font, allineamento e layout.

  • body: definisce lo sfondo, il font e il colore del testo.
  • margin: spazio esterno attorno agli elementi.
  • padding: spazio interno tra il contenuto e il bordo.
  • background: colore o sfondo dell'elemento.
  • color: colore del testo.
  • border: bordo dell'elemento.
  • border-radius: angoli arrotondati.
  • box-shadow: ombra per dare profondità.
  • display: flex: organizza gli elementi in fila o in colonna.
  • justify-content: allinea orizzontalmente gli elementi.
  • align-items: allinea verticalmente gli elementi.
  • gap: distanza tra gli elementi interni.
  • width e max-width: larghezza degli elementi.
  • :hover: stile applicato quando il mouse passa sopra.
  • :focus: stile applicato quando un campo del form viene selezionato.
  • @media: permette di creare versioni responsive per dispositivi mobili.

5. Cosa hanno in comune gli esercizi precedenti

Tutti gli esercizi usavano la stessa logica: prima costruivano la struttura HTML, poi applicavano uno stile CSS.

Es.1 Pagina aziendale con nav e sezioni Layout, gradient, animazioni, hover
Es.2 Modulo di registrazione Grid, campi form, bottoni colorati
Es.3 Pre-iscrizione conferenza Flexbox, valid/invalid, responsive design
Es.4 Form di contatto Semplice stile, hover e focus
Es.5 Spiegazione teorica Struttura base, layout semplice e leggibile

6. Conclusione

HTML definisce la struttura della pagina; CSS definisce il suo aspetto. Insieme permettono di creare siti web completi, ordinati e navigabili. Gli esercizi precedenti sono esempi di come si possono combinare tag e proprietà CSS per ottenere layout professionali e form interattivi.
